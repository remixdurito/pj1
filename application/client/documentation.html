About the application

Order Management App is an e-commerce tool used by the sales staff of our European store chain to create and consult customer orders.

Operations menu

Create a new order

Fill in the order code and the customer data (full name, address, email and phone). Tick the products the customer wants, enter the quantity for each one and press Send. The application shows the total price including 21% VAT and saves the order.

View orders

All orders: shows a table with every saved order.
One order: type an order code and the application shows only that order. If the code does not exist, an error is shown.
